# 🛡️ FinShield AI  
### Adaptive Anti-Bot Defense System

FinShield AI is an intelligent cybersecurity system designed to **detect, simulate, and mitigate bot attacks in real time**. It combines rule-based logic with adaptive detection techniques to identify threats such as brute-force attacks, bot traffic, and API abuse.

---

## 🚀 Features

- 🔐 **Brute Force Protection**
  - Detects repeated login attempts  
  - Temporarily locks user accounts  

- 🤖 **Bot Attack Simulation**
  - Simulates real-world attack scenarios  
  - Generates dynamic and varied attack patterns  

- 🧠 **Threat Intelligence**
  - Identifies VPN usage  
  - Detects bot behavior patterns  
  - Classifies attacks (XSS, API Abuse, Bot Pattern, etc.)  

- 📊 **Real-Time Dashboard**
  - Live traffic monitoring  
  - Threat analytics & visualization  
  - Detection accuracy metrics  

- 🧾 **Security Logs**
  - Credential attempt logs  
  - Account lockout tracking  
  - Blocked IP registry

## ⚙️ How It Works

1. User interacts with the system (login / traffic)  
2. Requests are analyzed in real-time  
3. Suspicious behavior is detected using patterns & rules  
4. System takes action:
   - Block IP  
   - Lock account  
   - Flag as threat  
5. All activities are logged and visualized in dashboard

- Mimics real bot behavior

## 🛠️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/your-username/finshield-ai.git

# Navigate to project folder
cd finshield-ai

# Backend setup
cd backend
pip install -r requirements.txt
python main.py

# Frontend setup
cd ../frontend
npm install
npm run dev
```
